# proguse animation groups for gfxres2apng.py
#
# One group per line; each group becomes one APNG. Every proguse PNG that is
# not listed here is a static image and is copied unchanged.
#
#   anim    FIRST-LAST  DELAY    frames are keys FIRST, FIRST+1, ..., LAST,
#                                each shown for DELAY milliseconds
#   button  OFF  ON  DOWN        3-frame APNG: frame 0/1/2 = off/on/down
#
# Output rules:
#   - Each APNG is named by the smallest key in its group, as 8 hex digits
#     plus ".PNG" (e.g. 00000301 00000300 00000302 -> 00000300.PNG).
#     The client must load a grouped key through its group's APNG and frame,
#     so this file is the mapping from old keys to (APNG name, frame index).
#   - Static images keep their 8-hex name, normalized to the ".PNG" extension.
#   - No trimming: every frame keeps the full source image size with offset 0.
#   - Button frames are selected by state, not played; their delay is unused.
#   - A "-" state is a fully transparent frame of the group's size.
#
# Keys are proguse filenames without ".PNG" (8 hex digits).
# "-" means the state has no image: nothing is drawn (e.g. no off state).
# Repeat a key to share one image between states (e.g. off == on).
# States need not be consecutive or ascending (e.g. 00000033 00000033 00000032).
# Each key may appear in at most one group.
# Everything after "#" is a comment. Annotations on generated lines:
#   WxH        image size (all images of a group have the same size)
#   file:line  client code that uses exactly these states
#   CONFLICT   other client code uses the same images with different states
#   guess      no client code reference; grouped by size and look only
